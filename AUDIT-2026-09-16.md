### U2 — Medium: cells need not resolve to unique row/column labels

`schema/cells.schema.json:27–50` permits independent label arrays; `reconcile.py:45–55` checks cell IDs against their own coordinates but never checks those coordinates against the label arrays. Read-only fixture mutations replacing both label arrays with index 99, or adding a conflicting duplicate row index 1, both returned `([], [])`.

No such current corpus cases were found. Add label-index uniqueness and membership checks in a separately scoped harness unit. This does not require contiguous indices or forbid intentionally sparse tables.

### U3 — Medium: self-target relations can manufacture coverage

`reconcile.py:63–79` checks reference existence, but permits a sum's target among its sources. A read-only fixture mutation with two zero leaves, target 999, and sources `[target, leaf1, leaf2]` returned GREEN. The target is covered without being derived from independent inputs.

No current self-target relations were found. Reject direct self-targets and add a regression. This finding does not assert that every possible graph cycle is invalid or that a generic graph framework is needed.

### U4 — Low for the present corpus: Decimal is not unlimited exact arithmetic

`reconcile.py:74,79,87` inherits the default Decimal context precision. Schema values have no digit bound (`schema/cells.schema.json:64–67`). A schema-valid read-only mutation containing `10000000000000000000000000000 + 1 = 10000000000000000000000000000` returned GREEN at default precision.

The largest current value has only 11 significant digits, so this is a boundary defect, not an observed failure in shipped data. Define an exact supported numeric domain or select sufficient local precision; do not silently rely on the ambient context.

### U5 — Medium: the documented sweep does not aggregate failure status

`README.md:64` runs a shell loop without failure accumulation or fail-fast behavior. A failing item followed by a passing item leaves exit status 0; reproduced with the same loop structure over exit statuses 1 then 0.

Pytest's intended scope is oracle self-tests plus corpus keying/encoding (`tests/test_reconcile.py:103–133`), not all corpus arithmetic. A read-only in-memory corpus mutation produced a reconcile violation while all 12 tests still passed. This is consistent with the README's self-test description, but means pytest cannot substitute for a reliable sweep. Fix the documented command to propagate any failure, or provide a single tested corpus gate with a nonempty-input check. `scratchpad/sweep.py` already aggregates actual failures but has the separate D6 empty-selection defect.

### U6 — Medium: the short auditor runbook omits established audit lessons

`RUNBOOK-auditor.md:10–13,30–42` orients a cold auditor toward a single-unit sample and checking declared relations with tolerance equal to observed delta. It does not include the later requirements to inventory available identity classes or test whether a tolerance is plausible for its stated reason.

Those omissions are explicitly explained at `DESIGN.md:72–98` and `BACKLOG.md:668–675`; the latter records that both the masked OPM typo and source non-closure satisfied `tol == delta`. Whole-batch practice is recorded separately at `NEXT.md:81–91`. The #430 placeholder provides the batch scope, but still does not explicitly ask the plausibility/completeness questions.

This is a newly filed instruction-propagation defect arising from an already documented August lesson, not a claim that the August remediation failed. Update the canonical short runbook before the next source audit, without treating this assessment as that audit.

### U7 — High consequence, historical rerun hazard: log repair discards unrelated suffix

`scratchpad/rebuild_weeklog.py:20–28` claims to replace one bad log entry, but writes only the preceding prefix and two fixed replacement lines. Every later entry is dropped if the marker is not the last entry. No such precondition is enforced. The path targets historical W29, not the present week; no current log loss was observed and the script was not run.

Preserve the suffix or enforce an exact historical-input precondition before any future execution. More generally, HEAD-based historical repairs are not safe against uncommitted current target changes.

### U8 — High consequence on reuse: observed discrepancy becomes its own tolerance

`scratchpad/build_june_t5_261_270.py:150–161,172–185` sets tolerance to any observed delta and quotes the general rounding footnote, with no independently justified upper bound. The shared helper serves June batches #261–#300. An arbitrarily large extraction error therefore receives enough slack to pass.

This is a retained-builder defect, not a newly proven wrong current Treasury value. A genuine rounding note does not authorize unlimited discrepancy. Require a source-appropriate bound and stop for adjudication above it; preserve already adjudicated source-side exceptions rather than inventing one universal bound.

### U9 — Medium, latent builder defect: filtering renumbers rows without remapping rollups

`scratchpad/build_june_t5_261_270.py:123–137` removes all-omitted rows and renumbers the rest, but lines 164–185 reuse caller-supplied row indices. Removing an earlier row can redirect or silently drop the intended rollup. Keep an original-to-retained index map or retain stable row coordinates.

The nearby fixed-position extraction also discards the selected label (`:251–254`) and can merge adjacent lines (`:83–92`). These are source-layout fragilities, not demonstrated current-source misalignment. No claim is made that existing callers presently trigger the all-omitted-row case.

### U10 — Medium, obsolete regeneration hazard: retained Table 6 builder predates repair

`scratchpad/build_remaining_mts.py:607–626,644–650` emits monthly identities only and marks remaining inputs standalone. It omits the fiscal-year identity required by `DESIGN.md:84–94`, and retains the confusing beginning-month label at line 594. Running it against corrected outputs would regress the August work.

This is the known historical identity gap surviving in a generator, NOT a finding that the current corpus still lacks the 673 restored identities. Treat this and other old builders as historical artifacts, not supported regeneration commands; retirement or explicit preflight protection may be preferable to broad refactoring.

### U11 — Low: public status and manifest presentation have drifted

`README.md:24–28` still shows the dated 421-unit snapshot and 245 Treasury units while also mentioning the newer August queue. Current counts are 430 and 254, with 71 August units remaining. `BACKLOG.md:29,34` each begin with `||`, shifting the Markdown columns. These are presentation defects, not missing tables. Update the snapshot and correct the two delimiters in a docs-sized follow-up.

## Compound findings

**U8 + U9:** row-index misalignment can produce wrong relations, while discrepancy-fitted tolerance absorbs their arithmetic errors. Restoring row mapping does not make unbounded tolerance safe, and bounding tolerance does not restore positional fidelity. Their combination is worse than either alone. Both remain retained-builder hazards; current corrupted output was not demonstrated.

D2 and D5 overlap in the FEC consistency block but are independent gate weaknesses: replacing `assert` prevents optimization from stripping the check, while required-file/key coverage prevents the check from passing vacuously. They need distinct repairs if the builder remains supported; no extra compound severity is assigned.

## Suggested fix order

Only real defects are listed; no fixes were applied.

1. Before any reuse, prevent destructive historical repairs and obsolete generators from overwriting current work (U7, U10, D7); do not blindly execute retained scripts as a regeneration pipeline.
2. For any builder that will be reused, fix unbounded tolerance and positional mapping together (U8, U9), then the incomplete FEC verification gate (D5, D2).
3. For current work, propagate the established audit questions into the short runbook (U6), adjudicate/repair the 55 role labels without changing values (U1), and complete the independent #422–#430 source audit. Keep #431+ blocked meanwhile.
4. In a scoped harness unit, add label integrity and self-target rejection (U2, U3), and a reliable nonempty full-corpus gate (U5, D6).
5. Lower priority: bound exact arithmetic semantics (U4), add a genuine numeric-float regression (D4), correct public docs (U11), and close reusable PDF handles (D3). D1 commentary cleanup is last, and not worth reviving obsolete tools for.
